# ガラガラポン

MRS TOOLSのボタン式ガラガラ抽選ツール。HTML / CSS / JavaScriptのみで動作します。
共通UIとオフライン処理は [MRS-TOOLS-TEMPLATE](https://github.com/MRS-TOOLS/MRS-TOOLS-TEMPLATE) をベースにしています。

## 使い方

1. 「賞の設定」で賞名・玉の色・個数を設定します（最大20種類、各0〜9,999玉、合計1玉以上）。
2. 「まわす」を押すと抽選器が回り、玉が1個出ます。
3. 出た玉を減らし、残りの玉から次の抽選を行います。
4. 「玉を元に戻す」で、設定した個数へ戻して履歴を消せます。

初期設定は1等1玉、2等3玉、3等6玉、参加賞20玉。
残っている玉1個あたりの確率が同じになるよう、Web Cryptoの乱数を使用しています。
履歴は最新200件まで保持し、抽選回数は全件を数えます。
設定変更の保存時には、確認後に残数・履歴がリセットされます。
設定を変更せず保存した場合は残数・履歴を維持します。

## 保存・オフライン

- 設定・残数・履歴は端末内のlocalStorageキー `mrs-garagara-pon-v1` に保存します。サーバー送信は行いません。
- ブラウザのデータ削除やプライベートブラウズでは、データが消える場合があります。
- 抽選結果はアニメーション開始前に保存するため、途中の再読み込みでも玉は戻りません。
- 別タブの保存を検知した場合は操作を止め、再読み込みを案内します。同時利用の厳密な排他制御はありません。抽選は1つのタブで行ってください。
- HTTPSまたはlocalhostで一度読み込み、Service Workerの準備が完了すれば、オフラインで起動・抽選・設定・履歴表示できます。
- 広告や外部リンクはオンライン時のみ利用可能です。初版には広告領域だけを用意しています。
- PWA用manifest・アイコン・インストール導線は含みません。

## ローカル確認

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。ビルド・外部ライブラリは不要です。
Cloudflare Pagesにはルートディレクトリの静的ファイルを配信してください。
Cloudflare設定や広告タグはこのリポジトリでは自動変更しません。

## 更新時

CSS / JSの `?v=1` とService Workerのキャッシュ対象を一致させ、`CACHE_NAME` のバージョンも更新します。
削除するのは `mrs-garagara-pon-` で始まる旧キャッシュのみです。
オンライン時はネットワーク優先、通信失敗時はキャッシュを利用します。

## 確認項目

抽選、連打防止、残数ゼロ、設定追加・削除・保存、リセットの取消、再読み込み後の保存復元、オフライン起動、スマートフォンの縦横表示、動きを減らす設定。
iPhone実機とCloudflare本番での確認は公開時に行ってください。
